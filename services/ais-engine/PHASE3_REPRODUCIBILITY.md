## score-v1

All component scores are constrained to `[0,1]`. The weights sum to `1.0`.

```text
investigative_priority_score =
    0.25 * origin_proximity_score
  + 0.15 * origin_dwell_score
  + 0.15 * release_time_alignment_score
  + 0.15 * corridor_alignment_score
  + 0.20 * behaviour_rule_score
  + 0.05 * lstm_continuous_score
  + 0.05 * dark_gap_score
```

The LSTM continuous component is the reconstruction-error-to-threshold ratio,
clipped to `[0,1]`. The frozen reconstruction threshold is
`0.06935688848908478`.

Current behaviour rules use low-speed, abrupt-turn, and sudden-speed-drop
signals. Their thresholds and the final ranking weights are controlled-demo
settings; they must not be described as operationally calibrated.

## Privacy proof

- Internal processing retains MMSI only in the restricted identity map.
- Public ranking, CSV, GeoJSON, gap and summary artifacts use `candidate_id`.
- The runner scans every public artifact for all restricted candidate MMSIs and
  fails if one is present.
- The automated test asserts `public_mmsi_exposure == false`.

## Ground-truth isolation proof

- The production pipeline accepts only the Phase 2 folder and AIS CSV path.
- The reproducibility runner creates an isolated temporary AIS directory.
- Only `ais_input.csv` is copied into that directory.
- `ground_truth.json` is neither copied nor passed to the pipeline.
- Both replay runs complete with the same three candidates and ranking.
